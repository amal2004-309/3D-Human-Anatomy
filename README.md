# 🫀 3D Human Anatomy & Organ Hotspot Engine

تطبيق ويب تفاعلي ثلاثي الأبعاد لاستكشاف تشريح جسم الإنسان، مع التركيز على **القلب النابض** و**الجهاز الهضمي**. تقدر تلف المجسم 360°، تضغط على أي عضو عشان تقرأ الشرح الطبي، وتدخل جوه القلب وتشوف الحجرات الداخلية.

---

## ✨ المميزات

- **مجسم ثلاثي الأبعاد** لجسم الإنسان مبني بـ Three.js.
- **نقاط تفاعلية (Hotspots)** على الأعضاء؛ الضغط على أي نقطة يركّز الكاميرا على العضو ويفتح لوحة الشرح.
- **أنظمة الجسم:** فلترة العرض حسب النظام:
  - الجسم بالكامل
  - الجهاز الهضمي
  - القلب والدوران
  - الجهاز العصبي
  - الجهاز التنفسي
- **الدخول إلى القلب:** وضع داخلي لاستكشاف الحجرات والصمامات، مع شرح لكل حجرة.
- **الجهاز الهضمي المخصص:** استكشاف مسار الطعام والأعضاء مع تمييز العضو المحدد.
- **مراقب نبض القلب (EKG):** رسم حي لنبضات القلب مع عرض معدل النبض (BPM).
- **صوت نبضات القلب:** تشغيل وكتم صوت النبض.
- **تحكم في الكاميرا:**
  - زوايا عرض جاهزة: أمامي، جانبي، علوي، خلفي
  - تدوير تلقائي
  - زر إعادة ضبط الوضعية
  - دليل الماوس داخل التطبيق
- **لوحة معلومات جانبية** لكل عضو فيها تبويبان: *نظرة عامة والوظائف* و*حقائق مذهلة*.
- **المحتوى مبني على ملف JSON**، فتقدر تعدّل أو تضيف أعضاء من غير ما تلمس الكود.
- **واجهة عربية بالكامل** (RTL).

---

## 🖱️ التحكم بالماوس

| الإجراء | النتيجة |
|---|---|
| زر الماوس الأيسر + السحب | تدوير المجسم 360° |
| عجلة الماوس | تكبير / تصغير |
| زر الماوس الأيمن + السحب | تحريك الكاميرا جانبياً (Pan) |
| الضغط على نقطة ملونة | التركيز على العضو وعرض الشرح |

## 🛠️ التقنيات المستخدمة

- [Three.js](https://threejs.org/) (`^0.182.0`) للرسوميات ثلاثية الأبعاد
- [Vite](https://vitejs.dev/) (`^6.2.0`) لبيئة التطوير والبناء
- JavaScript (ES Modules) و HTML و CSS
- Web Audio لصوت نبضات القلب
- خطوط Google Fonts: **Cairo** و **Outfit**

## 🚀 طريقة التشغيل

### 1. تثبيت الحزم

```bash
npm install
```

### 2. تشغيل المشروع

**من خلال الأمر:**

```bash
npm run dev
```

**أو على ويندوز:** اضغطي دبل كليك على الملف `start.bat`، وهيفتح المتصفح تلقائياً.

بعدها افتحي الرابط:

```
http://localhost:5173/
```

### 3. بناء نسخة للنشر

```bash
npm run build
```

### 4. معاينة النسخة المبنية

```bash
npm run preview
```

## 🧩 تعديل بيانات الأعضاء (JSON)

كل عضو هو عنصر داخل المصفوفة `hotspots` في الملف `src/data/anatomy-data.json`. مثال على الشكل المتوقع:

```json
{
  "hotspots": [
    {
      "id": "heart",
      "nameAr": "القلب",
      "nameEn": "Heart",
      "tag": "عضو حيوي",
      "color": "#ef4444",
      "summary": "ملخص طبي عن العضو...",
      "functions": [
        "ضخ الدم إلى أنحاء الجسم",
        "..."
      ],
      "funFacts": [
        "حقيقة مذهلة عن العضو..."
      ],
      "cameraFocus": {
        "position": { "x": 0, "y": 1, "z": 3 },
        "target":   { "x": 0, "y": 1, "z": 0 }
      },
      "internalView": {
        "chambers": [
          {
            "nameAr": "الأذين الأيمن",
            "nameEn": "Right Atrium",
            "desc": "يستقبل الدم غير المؤكسج من الجسم."
          }
        ]
      }
    }
  ]
}
```

**ملاحظات:**

- `internalView.chambers` خاصة بالقلب فقط (عنصر `id` بقيمة `heart`).
- أعضاء الجهاز الهضمي لازم يبدأ الـ `id` بتاعها بـ `digestive_` (مثل `digestive_stomach`) عشان يتم تمييزها في المجسم.
- `cameraFocus` بتحدد مكان الكاميرا وهدفها لما تضغطي على العضو.
